
제네릭 타입을 선언하면 자바 컴파일러 입장에서는 제네릭 타입(하단의 `T`)에 어떤 값이 들어올 수 예측할 수 없다.

```java
// T 에 어떤 타입이 들어올지 알 수 없음
public class ApplicationResolver<T> {
	private T applicationContent;
  
	public void apply() {
		applicationContent.apply(); // 불가능
	}
}

```

그래서 자바 컴파일러는 `T`를 어떤 타입이든 받을 수 있는 `Object` 타입으로 가정한다. 이러다 보니 특정 객체의 기능을 사용할 수 없게 된다. 

그래서 자바 컴파일러가 `T` 에 입력될 수 있는 값의 범위를 예측할 수 있도록 타입 매개변수의 **범위를 제한할 필요가 있다.**


```java
public class ApplicationResolver<T extends ApplicationContent> {
	private T applicationContent;
  
	public void apply() {
		applicationContent.apply(); 
	}
}

```


```java
public interface ApplicationContent {
	ApplicationResult apply();
} 
```

즉 위와 같은 방법으로 제네릭 도입 시 문제를 해결했다.
1. 제네릭에서 타입 매개변수를 사용하면 어떤 타입이든 들어올 수 있다.
	- 타입 매개변수 제한
